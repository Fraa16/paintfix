# Paintfix Markenleitfaden (Kurzfassung)

Zwei Welten, eine DNA. **Paintfix** ist die Dachmarke (Fahrzeugaufbereitung). **Paintfix Aviation**
ist die Luftfahrt-Division, nach dem Vorbild Mercedes-Benz / Mercedes-Maybach: gleiche Herkunft,
deutlich erkennbar anderer Auftritt.

## Logos

Alle Dateien liegen in `public/brand/` (SVG, vektorisiert, ohne Schrift-Abhängigkeit).

| Datei                                           | Verwendung                                            |
| ----------------------------------------------- | ----------------------------------------------------- |
| `paintfix-wordmark-graphite.svg` / `-white.svg` | Hauptlogo Paintfix auf hellem / dunklem Grund         |
| `paintfix-monogram-*.svg`                       | PF-Monogramm: Favicon, Profilbild, kleine Flächen     |
| `paintfix-aviation-lockup-on-navy.svg`          | Paintfix Aviation auf Navy (Standard)                 |
| `paintfix-aviation-lockup-on-light.svg`         | Paintfix Aviation auf hellem Grund                    |
| `paintfix-aviation-seal-gold.svg`               | Siegel (PF im Goldring): Stempel, Profilbild Aviation |

Regeln: nicht verzerren, keine Schatten oder Effekte, Schutzraum rundherum mindestens die Höhe
des „P“. Das Aviation-Siegel nie auf Automotive-Material verwenden, außer als Verweis auf die
Division.

|               | Automotive (Paintfix)                         | Aviation (Paintfix Aviation)                              |
| ------------- | --------------------------------------------- | --------------------------------------------------------- |
| Grund         | Weiß `#FFFFFF`, Papier `#F5F5F3`              | Mitternachtsblau `#0E1830`, Navy `#16223F`                |
| Flächen       | Graphit `#1A1D21`                             | Elfenbein `#F4F1EA` (Zwischenflächen)                     |
| Text          | Tinte `#111418`, Grau `#5B6168`               | Wolkenweiß `#F5F3EE`, Nebel `#A7AEBF`                     |
| Akzent        | Kobalt `#2447B8` (nur Buttons, Preise, Links) | Champagner-Gold `#C2A36B` (Linien, Icons, Umriss-Buttons) |
| Gold auf Hell | –                                             | Goldtinte `#7A5E30` (nur für Text)                        |

Kobalt ist der Kandidat für den Signature-Akzent und wird mit der Logo-Freigabe final.

## Schrift

Eine Schriftfamilie, zwei Haltungen: **Mona Sans** (Open Font License, lokal eingebunden).

- **Automotive:** normale Laufweite, Satzschrift-Groß/Klein, halbfett
- **Aviation:** **extra breit** (Breitenachse 125), **Versalien**, leicht gesperrt, wie bei Liberty Aviation
- Fließtext in beiden Welten gleich, mindestens 16 px

## Tonalität

| Automotive                                   | Aviation                                                    |
| -------------------------------------------- | ----------------------------------------------------------- |
| Direkt, konkret, nahbar, „Sie“               | Zurückhaltend, präzise, spezifikationsnah                   |
| Preise offen nennen („ab 99 €“)              | Keine Preise, „auf Anfrage, nach Muster und Umfang“         |
| Alltagsautos zeigen                          | Business Aviation, Golden Hour, Hangar                      |
| Keine Floskeln („innovativ“, „ganzheitlich“) | Fachbegriffe richtig: Turnaround, RON, FBO, AMM, Brightwork |

**Brücke:** Auf der Auto-Seite erscheint die Luftfahrt nur als Qualitätsbeweis, nie als Preissignal:
„Die Sorgfalt aus dem Hangar. Die Preise für Ihr Auto.“

**Trennung:** Auf der Aviation-Seite: „Eigene Produkte. Eigene Verfahren. Eigener Ansprechpartner.“

## Marken Dritter

CarPro, CQuartz, Aero-Sense, NUVITE und NuShine werden **als Produktnennung** verwendet.
Logos der Hersteller nur mit deren Freigabe. „Zertifiziert“ oder „Partner“ nur, wenn es
nachweislich stimmt.
