# Image brief: Paintfix & Paintfix Aviation

For Francesco (AI/stock production). Every image on the site is a named slot in
`src/content/media.ts`. Placeholders are generated by `npm run assets:placeholders` and carry a
"PLATZHALTER · …" label so you can see which slot is which on the preview.

## How to swap an image

1. Export the final file (WebP or PNG for alpha, at least the size listed below).
2. Put it in `src/assets/img/` (e.g. `src/assets/img/ai/av-sky.webp`).
3. In `src/content/media.ts`, point the slot's `file` at it and set `source`:
   `ai` | `stock` (add `credit` and `license`) | `client` (real Paintfix photo).
4. Build. Astro creates AVIF/WebP in all sizes automatically. There's no need to pre-compress.

## Hard rules (legal and brand)

- **Never** present AI or stock images as Paintfix's own work. They are mood only (UWG § 5).
  The before/after component refuses anything that isn't `source: client`.
- **Aircraft:** no visible registrations, no airline liveries, no manufacturer badges or logos.
  Generic business-jet shapes only.
- **People:** no stock faces that could be read as Paintfix staff. Passengers in a cabin are fine
  as clear mood shots.
- **Cars:** show **everyday cars** (Golf, Tiguan, Octavia, family SUVs) alongside one or two
  premium ones. Only Porsches would undo the "affordable" message.
- **Stock:** keep the licence and the credit line. Both go into `media.ts`, and the Impressum lists them automatically.

## Aviation: parallax hero layers (critical path, needed on day 3)

The hero is built from **separate layers** that move at different speeds. Deliver them separately:

| Slot             | File             | Size      | Alpha   | Content                                                                                                                                                          |
| ---------------- | ---------------- | --------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `av-sky`         | sky plate        | 2400×1400 | no      | Golden-hour sky above a cloud deck. Deep navy at the top, warm glow low right (sun at ~70 % x / 65 % y). **No clouds in the lower third**, those come as layers. |
| `av-clouds-far`  | far cloud band   | 2400×700  | **yes** | Distant, soft cloud tops, warm-lit, low contrast. Transparent above the cloud line.                                                                              |
| `av-clouds-mid`  | mid cloud band   | 2400×800  | **yes** | Cloud sea, more defined, warm tops, cooler undersides.                                                                                                           |
| `av-clouds-near` | near cloud band  | 2400×900  | **yes** | Big foreground cloud tops, bright rim light. These cross section borders on the site.                                                                            |
| `av-jet`         | aircraft cut-out | 1600×560  | **yes** | Generic midsize business jet, side-on to ¾ view, nose right, slight climb, warm rim light on the crown, white paint, no markings.                                |

**How to produce:** generate the full scene once for reference, then generate or cut each layer
separately. For the jet, generate on a neutral grey background and remove it (clean alpha,
no halo). The site adds a soft fade to the top of every cloud layer, so hard edges are fine.
